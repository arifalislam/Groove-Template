# Grove Framer Template

A converted Framer-friendly template for the Grove landing page.

## Included files

- `package.json` — basic Framer dependency and scripts
- `src/App.tsx` — converted homepage layout
- `src/index.tsx` — entry point for React/Framer projects
- `src/styles.css` — imported styles from the original template

## Usage

1. Open the folder in Framer or a compatible React environment.
2. Install dependencies with `npm install` or `yarn install`.
3. Run `npm run dev` to preview.
